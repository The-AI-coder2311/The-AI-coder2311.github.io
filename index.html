Selected work

Things I've built.

01

Project Chest

A research project on multi-label chest X-ray classification. I trained ResNet18 models on public datasets (NIH, CheXpert, PadChest, RSNA, MIMIC), then combined them with weight averaging ("model souping"). My best model reaches a macro AUC of 0.82 on a fully held-out external dataset (VinBigData). Entering ACSEF 2027.

PyTorch Python CNN pipeline Model souping

Project JARVIS

A harness for a local Ollama model that can take actions on your desktop, like opening apps, and remembers things between sessions using JSON-based memory.

Python Ollama Local LLMs

Melodique

A Python desktop music player with global media keys, Windows media overlay support, a mini player and song-change notifications — plus a companion server so an ESP32 with a touchscreen can work as a wireless remote.

Python ESP32 Desktop UI

Go-Kart Electronics

A custom PCB built around an ESP32-S3 that brings together I2C sensors — accelerometer, time-of-flight and temperature — with a TFT display for a go-kart.
